# Moon Delivery Ops

Небольшой игровой симулятор лунной доставки пайков. Игрок выбирает ровер и заказ на карте, оценивает вес, батарею, риск зоны и запускает рейс. Цель смены - заработать максимум кредитов за 7 дней и не уронить рейтинг базы.

## Стек

- Frontend: React + TypeScript + Vite
- Стили: Tailwind CSS
- Backend: Node.js + TypeScript + Fastify
- База данных: SQLite
- ORM: Drizzle ORM
- API: REST
- Тесты: Vitest
- Контейнеризация: Docker + Docker Compose

## Запуск

```bash
npm install
npm run dev
```

Игра открывается на `http://localhost:5173`, API работает на `http://localhost:8787`.

## Проверки

```bash
npm test
npm run build
```

## Игровая логика

- Тяжёлые заказы увеличивают расход батареи.
- Ровер не запускается, если не хватает батареи, грузоподъёмности или он на ремонте.
- Зоны карты отличаются скоростью и риском.
- В стартовых данных есть невозможный сценарий: сверхтяжёлый заказ не помещается ни в один готовый ровер.
- После рейса меняются деньги, рейтинг, батарея ровера, статус заказа, доставки и журнал событий.
